# Security

We take security seriously. Please do **not** open a public issue for a
vulnerability.

## Reporting

Email security@luranta.com with details:

- Affected package/version and endpoints
- A minimal reproduction
- Any relevant logs (redacted)

We aim to acknowledge receipt within 2 business days and to ship a fix in a
timely manner depending on severity.

## Supported versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark:  |
| < 0.1.0 | :x:                |
